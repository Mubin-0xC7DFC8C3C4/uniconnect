# Taste

## Read this before writing any UI

Before you write markup or CSS:

1. Open every image in design/references/. Look at them. Do not skip.
2. Read design/tokens.css. Every value must come from it.
3. Read any *-DESIGN.md in design/references/ for component rules.

## What this project looks like

- Editorial, not SaaS. Type-led. Big headline, real paragraph, generous air.
- One accent colour. Used for actions only, never decoration.
- Whitespace is design. When in doubt, remove element and add space.
- Motion explains change of state. It never announces itself.

## Banned by default

- Gradient text and gradient backgrounds
- Emoji as icons
- Three-column feature card grids with icon on top
- Drop shadows on anything not floating above page
- border-radius above 16px except pill button/avatar
- More than two font weights on one screen
- Centre-aligned body copy longer than two lines

If brief requires one, say so and ask first.
